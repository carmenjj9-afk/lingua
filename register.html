Instructor Registration

1Create your Google Sheet

Go to sheets.google.com, create a blank spreadsheet, and name it "Lingua Student Data". Keep it open.

2Create your Apps Script

In your sheet: Extensions → Apps Script. Delete the existing code. Paste the script from the lingua-sheets-script.js file Carmen sent you. Save (Ctrl+S). Then: Deploy → New deployment → Web app → Execute as: Me → Who has access: Anyone → Deploy → Authorize → Allow. Copy the Web app URL.

3Complete this form

Paste your Web app URL below and fill in your information. You will receive a unique instructor code to share with your students.

Please fill in all fields.
💡 Once registered, your unique code never changes. Share it with your students at the start of each semester.
